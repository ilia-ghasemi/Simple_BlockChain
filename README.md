# HashHop

A lightweight , minimal blockchain implementation bulid from scratch to demonstrate core cryptographic logging , block linking and basic consensus principles.

## Features

* **Cryptographic Block Linking:** Secure block hashing using keccak-256 to ensure data immutability.
* **Proof of Work (PoW):** basic mining algorithm with configurable difficulty.
* **Transaction Pool:** Simple mempool logic to handle pending transactions before block inclusion.
* **Chain Validation:** Built-in checks to verify block integrity and detect tampered data.
